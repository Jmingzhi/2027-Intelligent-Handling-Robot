# ICD · 机械电气接口控制文档

> **ICD = Interface Control Document（接口控制文档）**
>
> **为什么需要这份文档**：三人队最常见的死法不是技术难度，而是**装配时才发现对不上**——
> 相机安装孔位对不上、底盘尺寸和车道不匹配、串口协议两边理解不一致、坐标单位一个用 mm 一个用 m。
> 三人队 90% 的返工来自接口，不是来自算法。
>
> **⚠️ 铁律：任何一侧改动接口，必须先改这份文档 + 开 Issue + 通知另外两人。**
> 不允许"我先改了我的，你那边自己适配"。
>
> **关联**：[通信协议.md](通信协议.md) · [坐标系与标定约定.md](坐标系与标定约定.md) · [任务码定义.md](任务码定义.md)

### 4.2 关键数据结构

```
Workpiece（物料）
  color      : uint8   # 1=红 2=黄 3=蓝 4=绿 5=黑 6=浅蓝
  position   : {x, y}  # mm，坐标系见坐标系文档
  confidence : float   # 0.0-1.0

TaskCode（任务码）
  batch1_colors    : uint8[3]   # 第一批颜色顺序
  batch1_positions : uint8[3]   # 第一批放置环号 1-6
  batch2_colors    : uint8[3]   # 第二批颜色顺序
  batch2_positions : uint8[3]   # 第二批放置环号 1-6

PlacementRecord（放置记录）
  batch      : uint8
  color      : uint8
  ring_actual: uint8   # 实际落在几环（判定后填写）
  ok         : bool    # 是否按任务码正确

Statistics（统计，用于显示）
  grasp_correct  : uint8   # 正确抓取次数
  place_correct  : uint8   # 正确放置次数
```

### 4.3 任务状态机（建议）

```
IDLE
 └─► START（一键启动）
      └─► GOTO_QR          移动到二维码板前
           └─► READ_QR     读取二维码 → 解析任务码 → 显示任务码
                └─► GOTO_RAW1   移动到原料区
                     └─► PICK_B1 抓取第一批第 n 个（n=1..3）
                          └─► STOW   放入料仓（确认在位）
                               └─► (循环至 3 个)
                                    └─► GOTO_ROUGH  移动到粗加工区
                                         └─► PLACE_B1  按任务码放置（环号）
                                              └─► (循环至 3 个)
                                                   └─► PICK_ROUGH  从粗加工区取回
                                                        └─► GOTO_BUFFER 移动到暂存区
                                                             └─► PLACE_BUF  放置
                                                                  └─► GOTO_RAW2  回原料区
                                                                       └─► (第二批同理)
                                                                            └─► STACK  码垛
                                                                                 └─► GOTO_HOME  回启停区
                                                                                      └─► SHOW_STATS 显示统计
                                                                                           └─► DONE
```

> ⚠️ **每个状态必须设置超时**（规则：停止运行 15 秒本轮结束）。建议单状态超时 ≤ 3 s，并记录状态转移日志用于赛后分析。

### 4.4 错误处理约定

| 错误 | 处理 |
|---|---|
| 二维码识别失败 | 调整位置重试 ≤ N 次；仍失败则报错并显示（可获 0 分但避免更糟） |
| 抓取失败（抓空） | 重新定位；等待转盘下一圈；**记录失败计数，不影响继续执行** |
| 物料未上机 | **禁止前往下一区域**（规则硬要求），重试放置 |
| 视觉丢失目标 | 回退到上一稳定位姿重新搜索 |
| 落点偏差超预期 | **不得微调**（规则：再移动本轮结束），记录并继续 |
| 通信超时 | 重试 N 次后进入安全停止 |
| 低压告警 | 立即返回启停区（避免半路停机） |
