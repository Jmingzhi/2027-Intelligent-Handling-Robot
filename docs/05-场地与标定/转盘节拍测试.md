# 转盘节拍测试

> **为什么单独为转盘建一份文档**：原料区转盘是全赛项**最大的随机性来源**，且直接决定抓取时序。
> 官方参数：**φ300 mm 圆盘、高 80–100 mm、放 3 个物料呈 120°、匀速 6–10 秒/圈、转向随机、停位有误差**。
> 「6–10 秒/圈」是一个**范围**，说明不同场地的转盘转速不同，**必须实测并让软件自适应**。
>
> **关联**：[规则解读.md 第4.2节](../00-规则与命题/规则解读.md) · [场地尺寸实测绘.md](场地尺寸实测绘.md)

## 1. 官方给定参数

| 项 | 参数 |
|---|---|
| 形式 | 圆形电动转盘 |
| 直径 | φ300 mm |
| 总高度 | 80–100 mm |
| 容量 | 3 个物料 |
| 夹角 | 120° |
| 转速 | **匀速 6–10 秒/圈** |
| 转向 | **随机** |
| 停止位置 | 物料进入场地后的中间位置（**有误差**） |
| 每转停留 | 次数和时间**以现场为准** |

> ⚠️ 注意「每转停留次数和时间以现场为准」——意味着转盘**可能是间歇转动**（转一下停一下），而不是匀速连转。这一点**必须现场观察确认**。

### 2.2 转速测量方法（建议）

```
方法：在转盘边缘贴一个标记（或利用物料本身），
     用手机慢动作录像（120fps 或 240fps），
     记录标记转过一整圈所需帧数 → 秒/圈。
     重复 10 次，记录每次结果，统计均值与标准差。

更精确方法：用光电/霍尔传感器 + 示波器或 MCU 计数（若已有硬件）。
```

## 3. 抓取时序分析（实测后填写）

### 3.1 关键问题

> 从"机器人识别到目标颜色物料"到"可以开始抓取"，需要等多久？

| 情形 | 等待时间 | 说明 |
|---|---|---|
| 目标物料正好在抓取位 | 0 s | 最优 |
| 目标物料需转 120° 到抓取位 | 转速 × (1/3) | 若 6 s/圈 → 2 s；若 10 s/圈 → 3.33 s |
| 目标物料需转 240° 到抓取位 | 转速 × (2/3) | 若 6 s/圈 → 4 s；若 10 s/圈 → 6.67 s |
| 需等待转盘停稳 | 待实测 | 若有间歇停止 |

### 3.2 对总节拍的影响（★重要）

3 个物料，每个平均需等 **120°** 转动：

```
单个物料平均等待 = 转速 × (1/3)
若转速 8 s/圈 → 平均 2.67 s
3 个物料 → 约 8 s（第一批）
加上第二批 3 个 → 累计约 16 s
```

> ⚠️ **但这只是"等待"，还没算抓取动作本身。** 而总有效运行时间只有约 180 秒。
> ⚠️ **优化方向**：
> - 抓取顺序尽量顺应转盘转向（减少等待）
> - 转盘转动时**并行做其他事**（如同时完成视觉识别、料仓整理）
> - 考虑"一次转到位抓多个"是否可行（但规则要求**每次抓 1 个，放置到机器人上之后才能抓下一个**）

## 4. 软件应对策略（需实现）

| 需求 | 实现方式 | 状态 |
|---|---|---|
| 转速自适应 | 现场测量后输入参数，或视觉测速自动估计 | ⬜ |
| 转向自适应 | 不假设转向，靠视觉跟踪 | ⬜ |
| 停位误差容忍 | 抓取前重新视觉定位，不依赖"标称位置" | ⬜ |
| 间歇转动兼容 | 检测运动/静止状态，静止时才抓取 | ⬜ |
| 抓取时机预测 | 预测物料到达抓取位的时刻，提前动作 | ⬜ |
| 抓取失败重试 | 若抓空，等待下一圈（注意 3 分钟总时限） | ⬜ |
| 与"15 秒静止"约束配合 | 出发后等待转盘的同时要保证有可见动作 | ⬜ |

> ⚠️ **最后一项很关键**：规则规定"搬运机器人停止运行 15 秒，本轮比赛结束"（等待转盘转动时间增加 8 秒）。
> 所以**不能傻等**。正确的做法是：出发 → 先去读二维码（此时转盘在转）→ 再回原料区，把等待时间"藏"在路径里。
> **这个策略必须在实物上验证。**

## 5. 降级预案

| 风险 | 预案 |
|---|---|
| 转盘始终不停，无法抓取 | 设计"动态抓取"能力（机械臂跟踪）或选抓取窗口大的构型 |
| 停位误差超过预期 | 扩大机械臂容差；增加柔顺/被动导向 |
| 抓取位不确定 | 视觉闭环：每次抓取前重新定位物料中心 |
| 转速比预期慢（10 s/圈） | 重排抓取顺序；把读码放在等待窗口内 |
| 转速比预期快（6 s/圈） | 提高视觉帧率与响应速度 |
