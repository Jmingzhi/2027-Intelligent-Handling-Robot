## 4. 测量注意事项

1. **测量时不要踩踏/移动场地装置**，测完恢复原状
2. **拍照留证**：每项测量至少 1 张照片，含尺度参照物
3. **颜色采样**：用手机固定白平衡拍色卡，或用可读 RGB 的工具，每个区域至少取 5 点
4. **记录环境**：照明条件（自然光/灯光/遮光）对视觉方案影响巨大
5. **测 3 次**：场地布置本身有随机性，单次测量不可信
6. **优先测关键项**（若时间有限）：车道宽度 → 转盘高度与中心 → 圆环实际尺寸 → 启停区尺寸 → 二维码板距离
