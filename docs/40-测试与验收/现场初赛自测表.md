## 2. 官方计分项自测（核心）

> **计分规则回顾**：现场初赛总分按各队得分归一化（本队得分 / 参赛队最高得分 × 100）。
> 因此自测的重点不是"拿到多少绝对分"，而是**逐项确认能否稳定得分**。

### 项（1）正确读取二维码并在显示装置上显示任务码 —— 官方 1 分

| 子项 | 要求 | 本次结果 |
|---|---|---|
| 成功读取二维码 | 读到的码与裁判给定的**完全一致** | ⬜ 成功 ⬜ 失败 |
| 识别耗时 | ≤ ______ ms（记录） | |
| 显示装置正确显示 | 显示内容与二维码一致，**清晰可辨** | ⬜ 是 ⬜ 否 |
| 连续测试成功率 | ______ / 10 次 | |

**判定**：⬜ 得分　⬜ 部分得分　⬜ 不得分

> ⚠️ 规则：「**无法清晰辨认的不得分**」。所以显示装置的可读性是硬指标，不只是"显示了"。
