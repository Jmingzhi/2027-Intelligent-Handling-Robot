# 测试用例模板

> **文档定位**：本模板用于编写**可执行、可复现、可判定**的测试用例。
> 适用于单元测试设计、台架测试、场地测试与验收测试。
>
> **使用方式**：复制本文件，按测试批次命名（建议 `test/<类别>/TC-<编号>.md` 或集中成用例集文件），每条用例一个表格块。
>
> > ⚠️ **测试用例的核心是"预期结果"与"实际结果"的对照。**
> > 没有明确预期结果的测试，只是"操作了一遍"，不能称为测试。
>
> **关联**：[实验记录模板.md](实验记录模板.md) · [PR描述模板.md](PR描述模板.md) · [现场初赛自测表.md](../40-测试与验收/现场初赛自测表.md)

## 附一：本赛项必备的测试用例清单（建议）

> 这些是**规则红线与关键指标**，必须有对应的测试用例。详见 [合规检查表.md](../00-规则与命题/合规检查表.md) 与 [现场初赛自测表.md](../40-测试与验收/现场初赛自测表.md)。

| 类别 | 用例要点 | 判据 |
|---|---|---|
| 合规-尺寸 | 折叠态（含软质线路）投影与高度 | ≤300×300 mm，高 ≤400 mm |
| 合规-电源 | 电源数量与不可更换性 | 仅 1 个，装内部 |
| 合规-遥控 | 无任何遥控接收装置 | 无 |
| 合规-补光 | 仅垂直向下，无遮挡结构 | 符合 |
| 合规-显示 | 字高 ≥12 mm、不被遮挡（**含臂展开后**）、亮度 | 实测字符高度 |
| 合规-启动 | 只有一个启动按钮、标识明确、不被遮挡 | 符合 |
| 功能-读码 | 二维码识别成功率 | 连续 100 次 |
| 功能-颜色 | 6 色混淆矩阵（★ 浅蓝 vs 蓝） | 无明显不可分对 |
| 功能-圆环 | 圆环定位残差 | <1 mm |
| 功能-精度 | 落点进入目标环的比例 | 按环号统计 |
| 功能-上机 | 物料未上机时**禁止移动** | 必须拦截 |
| 功能-统计 | 显示计数与裁判口径一致 | 完全一致 |
| 边界-超时 | 每个状态超时行为 | 无 15 s 静止 |
| 边界-节拍 | 全流程耗时 | ≤150 s |
| 边界-越界 | 投影越界保护 | 不越界 |
| 异常-通信 | 断链/CRC 错/超时 | 可降级不卡死 |
| 异常-识别失败 | 读码失败、目标丢失、抓取失败 | 走降级路径 |
| 异常-低压 | 低压保护 | 安全收尾 |
| 性能-延迟 | 视觉端到端延迟 | 达标 |
| 性能-功耗 | 单轮功耗 | 容量可覆盖 |
| 回归-全流程 | 12 步完整流程 + 回位 + 显示 | 不中断 |

## 附二：编写测试用例的纪律

| # | 纪律 | 说明 |
|---|---|---|
| 1 | **预期结果必须可量化** | ❌"运行正常" → ✅"20 次中 ≥19 次落在 1 环内" |
| 2 | **前置条件必须写全** | 版本号、场地状态、参数配置 |
| 3 | **步骤要可复现** | 他人照着做能得到同样结果 |
| 4 | **边界与异常用例不可省** | 正常路径通常不是问题所在 |
| 5 | **必须保留测试数据** | 原始数据是判定依据（见 [实验记录模板.md](实验记录模板.md)） |
| 6 | **失败必须建 Issue** | 否则会丢失 |
| 7 | **回归用例要长期保留** | 修复过的问题必须持续防复发 |
| 8 | **合规用例优先级最高** | 合规失败是一票否决 |
