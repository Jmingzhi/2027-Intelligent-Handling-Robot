# 实验记录模板

> **文档定位**：本模板用于记录**每一次**硬件/软件/算法实验。
> 规则与仓库纪律要求："所有实验必须留记录"。
>
> **使用方式**：复制本文件到 `docs/30-实验记录/`，按编号规则命名（见 [README.md](../30-实验记录/README.md)），逐项填写。
>
> > ⚠️ **原始数据必须保留，不能只写结论。**
> > 只写"实验成功""精度达标"的记录，在赛后复盘时**没有任何价值**——
> > 因为你无法判断当时是否测错、无法复现、无法追踪退化。
>
> **关联**：[实验记录 README](../30-实验记录/README.md) · [测试用例模板.md](测试用例模板.md) · [待确认清单.md](../60-项目管理/待确认清单.md) · [风险登记.md](../60-项目管理/风险登记.md)

## 二、实验条件

> ⚠️ **版本信息必须完整**。缺少版本号的实验数据**不可比较**，也无法复现。

| 项 | 内容 |
|---|---|
| **硬件版本** | 结构版本 / 装配状态 / 关键件型号 |
| **固件版本** | 版本号或 Git 提交号 |
| **软件版本** | 视觉/算法版本或 Git 提交号 |
| **Git 提交号** | `git rev-parse HEAD` 的输出（完整或短号） |
| **参数配置** | 关键参数值（速度、阈值、超时等） |
| **环境条件** | 温度 / 湿度 / 地面材质与平整度 / 光照 |
| **使用物料** | 颜色 / 形状 / 数量 / 是否为正式物料 |
| **测量工具** | 工具名称、分辨率、校准状态 |
| **场地状态** | 是否标准场地 / 尺寸偏差 / 备注 |
