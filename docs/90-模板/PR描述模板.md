# PR 描述模板

> **文档定位**：本模板作为 `docs/90-模板/` 下的**留存副本**，实际使用时由 GitHub 自动套用
> `.github/PULL_REQUEST_TEMPLATE.md`。此处保留一份便于离线查阅与评审培训。
>
> **使用方式**：发起 Pull Request 时逐项填写。**"怎么验证的"一节不得为空。**
>
> > ⚠️ **没有验证证据的 PR 不予合并。**
> > "我本地跑通了"不是验证证据。照片、数据、日志、CI 结果才是。
>
> **关联**：[CONTRIBUTING.md](../../CONTRIBUTING.md) · [测试用例模板.md](测试用例模板.md) · [实验记录模板.md](实验记录模板.md) · [匿名提交检查清单.md](匿名提交检查清单.md)

## 三、★ 怎么验证的

> ⚠️⚠️ **本节是 PR 评审的重点。必须附证据：照片 / 数据 / 日志。**
>
> 禁止的写法：
> - ❌"本地测试通过"
> - ❌"应该没问题"
> - ❌"肉眼看起来 OK"
> - ❌"CI 过了"（CI 过只是必要条件，不是充分条件）

### 3.1 验证方式

| # | 验证方式 | 勾选 | 说明 |
|---|---|---|---|
| 1 | 单元测试 | ⬜ | 用例数 / 通过数 |
| 2 | 集成测试 | ⬜ | 场景说明 |
| 3 | 台架测试 | ⬜ | 测试条件 |
| 4 | 场地测试 | ⬜ | 场地状态 |
| 5 | 实机运行 | ⬜ | 运行轮次与结果 |
| 6 | 目视检查 | ⬜ | 检查项 |
| 7 | 静态检查 / Lint | ⬜ | 工具与结果 |
| 8 | 人工评审 | ⬜ | 评审人 |
| 9 | 其他 | ⬜ | |

### 3.2 验证证据（必须附）

| 证据类型 | 附件 / 链接 | 说明 |
|---|---|---|
| **照片** | | 硬件变更、装配结果、实测现场 |
| **数据表 / CSV** | | 实测数值，不要只写结论 |
| **日志文件** | | 运行日志、错误日志 |
| **视频** | | 动作过程（大文件走 LFS 或外链） |
| **CI 结果** | | Workflow 链接 |
| **测试报告** | | 引用 [测试用例模板.md](测试用例模板.md) 填写的用例 |

### 3.3 验证的量化结果

| 指标 | 变更前 | 变更后 | 是否达标 |
|---|---|---|---|
| | | | ⬜ 是　⬜ 否 |
| | | | ⬜ 是　⬜ 否 |

### 3.4 未验证的部分（必须诚实声明）

| 项 | 内容 |
|---|---|
| **是否影响接口** | ⬜ 否　⬜ **是** |

## 六、审核 Checklist

### 6.1 提交者自检（发起 PR 前）

- [ ] 已从最新 `develop` 拉取并解决冲突
- [ ] 提交信息符合规范（`<类型>(<范围>): <描述>`，并关联 Issue）
- [ ] **"怎么验证的"已填写，且附有照片/数据/日志**
- [ ] 未验证的部分已诚实声明
- [ ] 接口变更已同步更新接口文档
- [ ] 受影响的队友已通知
- [ ] 大文件已走 Git LFS
- [ ] 无调试残留（临时日志、硬编码路径、注释掉的代码块）
- [ ] 无 `TBD` 意外混入需要冻结的部分
- [ ] CI 通过

### 6.2 审核者检查（合并前）

- [ ] **验证证据充分**（不能只看"我测过了"）
- [ ] 改动范围与 Issue 描述一致（没有夹带无关改动）
- [ ] 接口变更已同步文档，且对端已知悉
- [ ] 未引入新的风险（若有，已登记）
- [ ] 未违反合规红线（成品件、尺寸、补光、遥控）
- [ ] 文档与代码一致
- [ ] 命名与代码风格符合 `CONTRIBUTING.md`
- [ ] 若有 `release/` 变更，已运行匿名检查

### 6.3 合规专项检查（涉及 `hardware/` 或 `release/` 时）

| # | 检查项 | 勾选 |
|---|---|---|
| 1 | 新增零件均为**自主设计**，未使用成品套件 | ⬜ |
| 2 | BOM"来源"列已填写 | ⬜ |
| 3 | [hardware/compliance/](../../hardware/compliance/README.md) 台账已同步 | ⬜ |
| 4 | 折叠态尺寸仍 ≤300×300×400 mm（含软质线路） | ⬜ |
| 5 | 未引入任何遥控接收装置 | ⬜ |
| 6 | 补光仍为垂直向下，未增加遮挡结构 | ⬜ |
| 7 | （若涉及 `release/`）匿名检查已通过 | ⬜ |
