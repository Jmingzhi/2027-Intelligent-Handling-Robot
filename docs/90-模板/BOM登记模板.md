# BOM 登记模板

> **文档定位**：本模板说明 **BOM（Bill of Materials，物料清单）** 的字段定义与登记规则。
> BOM 不只是"买什么、多少钱"——在本赛项中，BOM 的 **「来源」列是合规判定的依据**。
>
> **使用方式**：BOM 实际文件为 `hardware/bom/BOM.csv`；本模板用于说明字段含义与登记纪律。
>
> > ⚠️ **BOM 的「来源」列是合规关键。**
> > 规则原文："除标准件外，非标零件应**自主设计和制造**，**不允许使用购买的成品或采用成品套件拼装而成**。"
> > 每一行都要能回答："**这个零件，是不是我们自己设计的？**"
> > 答不上来 → 采购前就必须停下来。
>
> **关联**：[hardware/compliance/README.md](../../hardware/compliance/README.md) · [合规检查表.md](../00-规则与命题/合规检查表.md) · [机械方案.md](../20-技术方案/机械方案.md) · [PR描述模板.md](PR描述模板.md)

## 一、BOM 字段定义

| # | 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| 1 | **序号** | ✅ | 行号，从 1 开始，**不复用** | `1` |
| 2 | **零件名称** | ✅ | 通用可读名称，不要写口语化昵称 | `底盘底板` / `M3×8 内六角螺钉` |
| 3 | **类别** | ✅ | 结构件 / 传动件 / 紧固件 / 电子件 / 线材 / 其他 | `结构件` |
| 4 | **来源** | ✅★ | **见第二节，合规关键** | `自制-3D打印` |
| 5 | **规格型号** | ✅ | 具体规格；自制件填"见图纸编号" | `M3×8` / `见 DWG-012` |
| 6 | **数量** | ✅ | 单台用量（含备件请注明） | `4` |
| 7 | **单价** | ✅ | 元；自制件填材料成本或 0 | `0.15` |
| 8 | **小计** | ✅ | 单价 × 数量 | `0.60` |
| 9 | **供应商** | 🟡 | 外购件填；自制件填"自制"或代打服务商 | `自制` / `XX代打` |
| 10 | **用途位置** | ✅ | 用在哪里，便于查证 | `底盘第 2 层，固定电机座` |
| 11 | **合规判定依据** | ✅★ | **为什么这个来源是合规的** | `自主设计，见 CAD/xxx.step，2027-03-01 打印` |
| 12 | **备注** | ⬜ | 风险提示、替代方案、待确认 | `⚠️ 待确认是否算标准件` |

## 二、★ 「来源」列的取值（合规关键）

> ⚠️ **「来源」列只能取以下四类之一，不允许留空。**

| 取值 | 含义 | 是否允许 | 需要什么证据 | 台账对应 |
|---|---|---|---|---|
| **`自制-3D打印`** | 自主设计并用 3D 打印制造（含外协代打） | ✅ 允许 | 设计源文件（`.step`/`.stl`）+ 打印记录/照片 | 必须登记 |
| **`自制-机加工`** | 自主设计并机加工/激光切割制造 | ✅ 允许 | 设计源文件 + 加工照片 | 必须登记 |
| **`标准件-外购`** | 符合"标准件"定义的外购件 | ✅ 允许 | 购买订单截图 + 规格说明 | 建议登记 |
| **`⚠️待确认`** | 尚未判定，或属灰色地带 | ⚠️ **临时状态** | — | **必须登记且必须清零** |

### 2.1 什么算"标准件"

> 判定原则见 [合规检查表.md](../00-规则与命题/合规检查表.md) 1.1 节。**典型标准件**：

| 类别 | 例子 |
|---|---|
| 紧固件 | 螺钉、螺母、垫圈、卡簧、销、弹簧 |
| 轴承与导向 | 轴承、直线轴承、光轴、导轨（标准系列） |
| 传动件 | 标准齿轮、同步带、同步带轮、链条、丝杆+螺母副、联轴器 |
| 型材 | 标准铝型材、角件 |
| 执行元件 | **标准**舵机、**标准**电机 |
| 传感元件 | **标准**传感器模块 |
| 电子元件 | 电阻、电容、芯片、标准模块 |

### 2.2 什么**禁止**（不可写入 BOM 作为方案）

| 类别 | 例子 | 后果 |
|---|---|---|
| 成品套件 | 成品机器人底盘、成品机械臂、成品套件车 | ❌ 取消资格 |
| 成品抓取模块 | 成品夹爪总成 | ❌ 取消资格 |
| 非标结构件 | 购买的底板、支架、连接件、夹爪、料仓、外壳、转接件 | ❌ 取消资格 |
| 成品亚克力切割件 | 现成切割件 | ❌ 非标结构件 |
| 他人开源图纸的打印件 | 直接下载打印 | ❌ 非"自主设计" |

### 2.3 灰色地带（写 `⚠️待确认` 并尽快澄清）

| 情形 | 风险 | 处理 |
|---|---|---|
| 成品金属舵机支架 | ⚠️ 高风险（通常属非标结构件） | 尽量自制；否则保留证据并澄清 |
| 成品履带 / 轮胎 | 🟡 通常视为标准件 | 保留购买记录 |
| 成品电机驱动板 / 降压模块 | 🟡 电控模块一般可接受 | 建议尽量自制 PCB（也利于创意分） |
| 成品 PCB 模块 | 🟡 需评估 | 同上 |
| 成品码盘 / 编码器 | ✅ 标准件 | — |
| 成品丝杆+螺母副 | ✅ 标准件 | — |
| 3D 打印服务代打（自己设计） | ✅ 合规 | 保留设计文件与打印记录 |

> ⚠️ **任何一个 `⚠️待确认` 都必须在赛前清零**。
> 赛前仍为"待确认"的，视为风险（见 [风险登记.md](../60-项目管理/风险登记.md)）。

## 四、登记规则

### 4.1 登记时机

| 时机 | 要求 |
|---|---|
| **设计阶段** | ★ 设计定型时就标注每个零件的"来源"（不要等采购完再补） |
| 采购前 | 检查该零件是否会引入 `⚠️待确认`；如是，**先澄清再买** |
| 采购后 | 补全供应商、单价、订单号 |
| 自制件加工后 | 补全证据文件路径与加工日期 |
| 装配后 | 核对实际用量与 BOM 是否一致 |
| 每次结构变更 | **同步更新 BOM**（见 [PR描述模板.md](PR描述模板.md) 5.1 节） |

### 4.2 与合规台账的对应关系

```
hardware/bom/BOM.csv                        hardware/compliance/台账
┌────┬──────────┬──────────────┐          ┌────┬──────────┬──────────────┐
│序号│ 零件名称  │ ★ 来源        │          │零件名│ 来源判定  │ ★ 判定依据   │
├────┼──────────┼──────────────┤          ├────┼──────────┼──────────────┤
│ 1  │ 底盘底板  │ 自制-机加工   │◄────────►│底盘底板│ 自制     │ 设计文件+照片 │
│ 2  │ 电机座    │ 自制-3D打印   │◄────────►│电机座  │ 自制     │ 设计文件+照片 │
│ 3  │ M3×8螺钉  │ 标准件-外购   │◄────────►│（可略）│ 标准件   │ 订单截图      │
└────┴──────────┴──────────────┘          └────┴──────────┴──────────────┘
        ★「来源」列必须与台账的「来源判定」一致
```

> ⚠️ **两份文件的「来源」必须一致**。
> 不一致 = 说明至少有一处是事后补写 = 证据链不可信。
> 详见 [hardware/compliance/README.md](../../hardware/compliance/README.md)。

### 4.3 必须保留的证据

| 零件类型 | 必须保留的证据 | 存放位置 |
|---|---|---|
| 自制-3D打印 | 设计源文件（`.step`/`.stl`）、打印参数或打印记录、实物照片 | `hardware/cad/`、`hardware/compliance/` |
| 自制-机加工 | 设计源文件、加工图纸、加工过程/成品照片 | `hardware/drawings/`、`hardware/compliance/` |
| 标准件-外购 | 购买订单截图（含规格、日期）、必要时规格书 | `hardware/compliance/` |
| ⚠️待确认 | 澄清记录（向裁判/组委会的书面问答） | `hardware/compliance/` |

> 💡 **证据的另一重价值**：加工过程照片对**创意设计"合理性/制造精细"（30 分）**也有帮助。
> 保留证据是一举两得的事。

## 五、BOM 维护纪律

| # | 纪律 | 理由 |
|---|---|---|
| 1 | **「来源」列不允许留空** | 留空 = 合规状态未知 |
| 2 | **`⚠️待确认` 必须清零** | 赛前仍为待确认 = 风险 |
| 3 | **BOM 与合规台账必须一致** | 不一致说明证据链断裂 |
| 4 | **每次结构变更同步更新 BOM** | 否则 BOM 与实际不符 |
| 5 | **序号不复用** | 便于历史追溯 |
| 6 | **价格必须真实** | 便于预算控制与答辩说明 |
| 7 | **自制件也要填成本** | 不要填 0 了事（材料成本要计入） |
| 8 | **BOM 纳入版本控制** | 变更可追溯 |
| 9 | **备件单独标注** | 规则允许带标准件备件（见 [规则解读.md](../00-规则与命题/规则解读.md) 9.4） |
| 10 | **不采购任何"成品套件"** | 一票否决 |

### 5.1 常见错误

| ❌ 错误 | ✅ 正确 |
|---|---|
| 来源留空 | 必须四选一 |
| 把购买的结构件写成"标准件-外购" | 非标结构件**不能买**，只能自制 |
| 用开源图纸打印后写"自制-3D打印" | ⚠️ 非"自主设计"，必须重新设计 |
| 买成品夹爪后写"标准件-外购" | ❌ 成品抓取模块属禁止项 |
| 事后补写来源 | 设计阶段就标注 |
| BOM 与台账各写一套 | 必须一致 |
| 自制件单价填 0 | 填材料成本 |
