## ★ 本赛项的两条硬约束

### 1. 尺寸（违反即取消资格）

> 「搬运机器人（含机械手臂）最大外形尺寸满足**铅垂方向投影不大于边长 300 mm 的正方形**，**高度不超过 400 mm**，包括**所有软质线路**等都必须在此尺寸范围内方可参赛。允许机械臂结构为**可折叠形式**，但**出发后方可自行展开**，**展开后尺寸不受上述限制**。」

**设计含义**：
- 折叠态必须 ≤ **300 × 300 × 400 mm**（含线材）
- **折叠臂是官方允许且鼓励的路线**：车体做小、臂做大
- 规则评"越界"时**机械臂除外** → 抓取可靠臂伸出，车体留车道内

### 2. 采购（违反即取消资格）

> 「除**标准件**外，非标零件应**自主设计和制造**，**不允许使用购买的成品或采用成品套件拼装而成**。」

**设计含义**：
- **不能买成品底盘、成品机械臂、成品套件**
- 标准件（螺钉、轴承、型材、标准舵机/电机/传感器模块、同步带、丝杆）可买
- **每一个非标零件必须在 [`compliance/`](compliance/) 登记**
- **BOM 的"来源"列必须与台账一致**

详见 [compliance/README.md](compliance/README.md) 与 [../docs/00-规则与命题/合规检查表.md](../docs/00-规则与命题/合规检查表.md)

## 关键设计输入（来自规则）

| 项 | 参数 | 影响 |
|---|---|---|
| 车道宽度 | 400 mm | ★车体投影必须留余量（建议 ≤280 mm） |
| 机器人折叠态 | ≤300×300×400 mm | ★含软质线路 |
| 转盘 | φ300 mm，高 80–100 mm | ★机械臂 Z 行程与臂展 |
| 圆环区 | 580 × 150 mm | ★臂展 |
| 圆环 1 环外径 | φ + 3 mm（φ=物料最大直径） | ★落点精度需求来源 |
| 物料 | ≤80 mm，≤100 g | 夹持力需求不高，但夹持面积要够 |
| 障碍物 | φ50 × 100 mm，随机 | ★越障 or 绕行的决策 |

## 编码与命名约定

| 项 | 约定 |
|---|---|
| 零件命名 | `part-名称-版本`，例 `part-抓手基座-v2.SLDPRT` |
| 装配命名 | `asm-名称-版本`，例 `asm-抓手总成-v3.SLDASM` |
| 工程图命名 | `dwg-名称-版本`，例 `dwg-底板-v1.pdf` |
| 版本 | 用 `v1` `v2` `v3`，**不要用**"最终""最新" |
| 单位 | **mm**，全局统一 |
| 螺钉 | 主结构统一 **M3**，精密件 M2/M2.5（避免工具混乱） |
