# BOM（物料清单）

> 本目录存放全机物料清单。**BOM 的"来源"列是购件合规的关键**，必须与 `hardware/compliance/` 台账一一对应。

| 文件 | 用途 | 维护人 |
|---|---|---|
| `BOM.csv` | 机读版，用于统计成本、重量、数量 | B |
| `BOM.md` | 人读版，用于评审与展示 | B |

## 字段定义

| 字段 | 说明 |
|---|---|
| 序号 | 连续编号 |
| 零件名称 | 见名知意 |
| 类别 | 结构件 / 传动件 / 紧固件 / 电控 / 传感 / 电源 / 显示 / 其他 |
| **来源** | ★`自制-3D打印` / `自制-机加工` / `自制-激光切割` / `标准件-外购` / `⚠️待确认` |
| 规格型号 | 具体型号或尺寸 |
| 数量 | 单机用量 |
| 单价(元) | — |
| 小计(元) | 数量 × 单价 |
| 供应商 | 采购渠道 |
| 用途位置 | 装在哪里 |
| **合规判定依据** | ★为什么它算标准件 / 为什么允许外购 |
| 重量(g) | 用于重量预算 |
| 备注 | — |

## ⚠️ 必须遵守的合规要求

规则原文：

> 「除标准件外，非标零件应**自主设计和制造**，**不允许使用购买的成品或采用成品套件拼装而成**。」

违反后果：**取消比赛资格**。

因此：

1. **每一个非标准件都必须在 `hardware/compliance/` 登记**
2. **每一个"标准件-外购"都要能说明为什么它是标准件**
3. 灰色地带（成品舵机支架、成品 PCB 模块、开源项目图纸）**必须向裁判澄清后再采购**
4. 保留证据：设计源文件、加工照片、购买订单截图

详见 [../compliance/README.md](../compliance/README.md) 与 [../../docs/00-规则与命题/合规检查表.md](../../docs/00-规则与命题/合规检查表.md)

## 统计要求

BOM 应能自动汇总出：

- 总成本（对比 [../../docs/60-项目管理/待确认清单.md](../../docs/60-项目管理/待确认清单.md) 中的预算上限）
- 总重量（用于电机选型与打滑评估）
- 自制件 / 标准件 的数量比例（合规自查）
