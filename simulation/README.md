# 仿真

> 仿真用于**在实物做出来之前验证算法逻辑**，以及在实物不空闲时做回归测试。

## 仿真的价值与本项目的取舍

| 用途 | 价值 | 本项目建议 |
|---|---|---|
| 验证任务状态机逻辑 | 高（不需要硬件） | ✅ 优先做 |
| 验证路径规划 | 中高 | ✅ 做（车道约束容易仿真） |
| 验证转盘抓取时序 | 中（时序逻辑可仿真，物理接触不可靠） | 🟡 部分 |
| 验证机械臂运动学 | 中 | 🟡 视臂构型 |
| 验证视觉识别 | 低（真实色差、反光难仿真） | ❌ 不划算 |
| 验证落点精度（±1.5mm） | **很低** | ❌ **必须实物验证** |

> ⚠️ **不要陷入"仿真做得很漂亮但实物没动"的陷阱。**
> 三人队时间有限，仿真应聚焦在**不需要物理接触就能验证的逻辑**上：
> 状态机、路径规划、任务码解析、时序调度。
>
> **精度类指标（±1.5 mm 落点、颜色识别）无法靠仿真验证，必须实物实测。**

## ⚠️ 是否需要仿真：这是一个待决策项

硬件未定，是否引入仿真平台（Gazebo / Webots / 自写简易仿真）**尚未决定**。

| 因素 | 支持仿真 | 反对仿真 |
|---|---|---|
| 时间成本 | 状态机调试快 | 搭建环境耗时 |
| 硬件可用性 | 硬件只有一套，仿真可并行 | — |
| 精度验证 | — | 仿真精度不真实 |
| 学习成本 | — | 三人队无人熟悉 |

## 如果采用仿真，建议范围

**只做"逻辑仿真"**：用 Python 写一个轻量级仿真器，模拟：

- 场地坐标系与车道约束
- 机器人位置与移动耗时（用实测速度参数）
- 转盘转速与物料相位
- 机械臂动作耗时
- 任务状态机流转

**不做**：物理接触、视觉渲染、力学。

这样可以在实物不空闲时验证"能不能在 3 分钟内跑完"这类问题。
