## 登记要求

每个模型必须能回答：

1. **它做什么**（颜色分类？形状分类？圆环检测？二维码？）
2. **精度如何**（在哪个测试集上、什么指标、多少）
3. **用哪批数据训练的**（对应 `vision/dataset/` 的版本）
4. **如何复现**（训练脚本在哪、超参数是什么）
5. **推理耗时**（在本机/目标硬件上多少 ms）★影响节拍

## ⚠️ 重要提示

| 提示 | 说明 |
|---|---|
| **推理耗时是硬指标** | 3 分钟节拍下，模型推理必须足够快。记录了才能评估 |
| **决策：是否需要学习型方法** | 颜色识别可能用 HSV 就够了；形状识别可能需要模型。避免过度工程 |
| **模型必须能在目标硬件上跑** | 若用 MCU，需量化/TFLite Micro；若用上位机，可选空间大。**硬件未定，此项 TBD** |
| **保留训练配置** | 超参数、数据划分、随机种子都要记录，否则无法复现 |
