# 视觉数据集

> ⚠️ **本目录的数据集内容不入库。** `.gitignore` 已排除 `raw/` 与 `processed/`。

## 为什么数据集不入库

| 原因 | 说明 |
|---|---|
| 体积巨大 | 图片/视频数据集动辄数百 MB 到数 GB，GitHub 仓库无法承受 |
| 版权问题 | 部分数据集来源有版权限制，不适合公开 |
| 可重新生成 | 采集脚本 + 原始素材可复现，无需存快照 |

## 目录约定

```
dataset/
├── raw/            # 原始采集，不入库
├── processed/      # 标注/处理后，不入库
├── labels/         # 标注文件（小型，可入库）
└── README.md       # 本文件
```

## 数据集如何共享

| 方式 | 做法 |
|---|---|
| 外部网盘 | 上传后**在本文件登记下载链接 + 校验和（SHA256）** |
| 校园内网 | 登记共享路径 |
| 自制小数据集 | 若 < 10 MB，可考虑放入 `labels/` 或 `samples/`（先确认） |

## 本项目需要的数据集

| 数据集 | 用途 | 数量目标 | 状态 |
|---|---|---|---|
| 物料颜色样本 | 6 色识别（含色差变化） | 每色 ≥ 200 张 | ⬜ |
| 浅蓝 vs 蓝 对比集 | ★专项：区分最易混的两色 | ≥ 400 张 | ⬜ |
| 圆环图像 | 1–6 环定位 | ≥ 300 张 | ⬜ |
| 二维码图像 | 读码（不同距离/角度/光照） | ≥ 300 张 | ⬜ |
| 转盘场景 | 转盘上物料的定位 | ≥ 300 张 | ⬜ |
| **形状样本（决赛用）** | 圆柱/方形/三角/球/锥/组合体 | ≥ 600 张 | ⬜ |
| 码垛场景 | 判断物料是否平稳叠放 | ≥ 200 张 | ⬜ |

> ⚠️ **浅蓝 vs 蓝 是本项目最易误判的一对**（浅蓝是 PLA、蓝色是 ABS，材料与色调都接近）。
> 必须专门构建对比数据集并测试区分度。

> ⚠️ **决赛物料形状会变化**（规则：圆柱体、方形体、三角形、球体、锥体及组合体）。
> 视觉方案不能只做颜色，**必须预留形状识别能力**。

## 数据采集注意事项

- [ ] 覆盖不同光照条件（现场仅允许垂直向下补光，但环境光会变化）
- [ ] 覆盖不同距离与角度
- [ ] 覆盖色差变化（规则明确"物料可能会有一定色差"）
- [ ] 覆盖遮挡/反光等异常情况
- [ ] 标注规范统一，标注工具与格式记录在此
- [ ] 采集脚本归档到 `tools/` 或 `vision/src/`
