# 测试

> 本目录存放测试用例与测试数据。测试分三类，**分别对应不同的验证目的**。

## 目录

| 目录 | 用途 | 何时用 | 负责人 |
|---|---|---|---|
| `bench/` | **台架测试** | 单个模块或机构的验证（抓取成功率、落点精度、通信） | B / C |
| `field/` | **场地测试** | 整机在真实/模拟场地上的运行测试 | B / C |
| `acceptance/` | **验收测试** | 对照官方评分项的整体验收 | A |

## 三类测试的区别

| 类型 | 环境 | 目的 | 输出 |
|---|---|---|---|
| 台架 | 实验台 | 快速迭代，验证单个指标 | 指标数据（成功率、精度、耗时） |
| 场地 | 2400×2400 场地 | 验证集成后的实际表现 | 全流程时间剖面 + 问题清单 |
| 验收 | 模拟比赛流程 | **确认能拿多少分** | [现场初赛自测表](../docs/40-测试与验收/现场初赛自测表.md) |

## 命名规范

```
YYYYMMDD-测试项-序号
例：
  20270315-落点重复精度-01.csv
  20270315-转盘抓取成功率-01.md
  20270320-全流程时间剖面-01.md
```

## 测试记录要求

每次测试必须记录：

- **Git 提交号**（否则数据无法复现）
- 固件版本、视觉参数版本
- 硬件状态（有无改动）
- 环境条件（场地、光照、电池电压）
- **原始数据**，不只写结论

用 [测试用例模板](../docs/90-模板/测试用例模板.md) 或 [实验记录模板](../docs/90-模板/实验记录模板.md)。

## 关键指标（本项目）

| 指标 | 目标 | 说明 |
|---|---|---|
| 落点重复精度 | **≤ ±1.0 mm** | 1 环要求约 ±1.5 mm |
| 1 环命中率 | ≥ 70% | 15 分 vs 2 环 10 分 |
| 2 环以内比例 | ≥ 95% | — |
| 转盘抓取成功率 | ≥ 90% | — |
| 二维码识别成功率 | ≥ 99% | — |
| 颜色识别准确率 | ≥ 99% | 浅蓝 vs 蓝最易混 |
| 码垛成功率 | ≥ 90% | — |
| 全流程时间 | **≤ 150 s** | 3 分钟限时，留 30 s 余量 |
| 连续成功次数 | ≥ 5 次 | 稳定性 |
